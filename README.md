# Microprogrammed-CPU-in-VHDL
This project implements a **Microprogrammed CPU** on the **Altera DE2-115 FPGA board** using **VHDL** and structural modeling.   The CPU architecture includes a custom microsequencer, micro-ROM, RAM, and an 8-bit datapath supporting instruction fetch, decode, execution, stack operations, arithmetic, branching, and halting.
